# Kapuruka AI Sourcing Agent (Kapuruka.com AI Mode)

An intelligent, premium B2B sourcing workspace powered by AI, built for **Kapuruka.com**. Go beyond traditional searches and streamline wholesale sourcing workflows with conversational AI, interactive products panels, and chat-based controls.

## 🌟 Key Features

*   **Rebranded Premium Design**: Styled around the official Kapuruka brand theme colors (Deep Purple `#402970` and hover variants) and powered by the modern *Plus Jakarta Sans* typeface.
*   **Viewport-Locked Interface**: A sticky layout designed to behave like a native desktop app: sidebar navigation, header, and input fields remain locked to the display height while only the chat timeline is scrollable.
*   **Horizontal Suggestions Row**: Dynamic search ideas sit scrollable directly under the chat input card, complete with a circular navigation indicator control.
*   **Deliver To Popover**: A hover-triggered location manager component matching top-tier e-commerce delivery controls, complete with country lists and ZIP/postal code inputs.
*   **Simplified Navigation**: Quick-access sidebar containing *Home*, *History* (with Status indicator dots), and *Contact us*.
*   **Adaptive Theme**: Supports both chat focus view and centralized hero search engine landing view.

## 🚀 Getting Started

### Prerequisites

*   Node.js (v18 or higher recommended)
*   npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/AbQaadir/kapuruka-ai-shopping-agent.git
   cd kapuruka-ai-shopping-agent
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Launch the local development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

---

## 📦 Building for Production

To create an optimized production build:

```bash
npm run build
npm run start
```
